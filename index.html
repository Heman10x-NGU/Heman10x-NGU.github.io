openJev Verdict

2026 · 405 stars

A 151M model that makes typed decisions in about 20 ms, and beat models up to 230 times its size on JevBench.

Most automation asks a chat model for JSON, then parses it and retries when it breaks. Verdict skips generation. One forward pass over ModernBERT returns a typed choice, score, or yes/no with a calibrated confidence, so plain code can decide when to act and when to hand off to a person. Version 1.4 fixed three inference bugs without retraining and moved the JevBench score from 66.2 to 74.9. On the 20 September leaderboard that put it first among open models, ahead of models with 9B to 35B parameters, GPT-5.6 Luna, and Gemini 3.1 Flash-Lite. Verdict 2.0, a separate fine-tune, beats TypeSafe's Jev and the 421M Laya on typed-decisions.

expert-stream

2026 · C++ / llama.cpp

A 284B model generating text on a 16 GB laptop. Its published memory floor is 96 GB.

DeepSeek V4-Flash is 82.5 GB on disk, but each token only uses 6 of 256 experts per layer. So the engine leaves the experts on the NVMe SSD and streams in the ones each token picks. Stock llama.cpp died after two tokens on this machine; capping the working set lets it run to completion, and the greedy output is byte-identical. It's slow, under one token a second, and the repo shows where every second goes. Before writing any code, I tested about twenty ideas borrowed from biology and physics, from immune memory to the way DNA packs a body into a small genome. Most turned out to be a cache under a new name. The compression idea lasted an hour: real expert weights measured barely more compressible than random noise.

FractalMem

2026 · Private for now

Memory for long-running coding agents. Compact the context, keep the evidence.

When an agent compacts its context, the summary drops the details it needs an hour later, like the exact name of a function. FractalMem stores redacted events in SQLite, builds a hierarchical summary that only appends, so the prompt prefix stays stable for caching, and lets the agent search exact symbols and text over MCP.

nanoserve

2026 · Python / MLX

A small inference engine for Apple Silicon with continuous batching, prefix caching, and OpenAI-compatible streaming.

Running one prompt locally is easy. Serving overlapping requests is where the real problems are: who owns the KV cache, when to reuse a prefix, and how to schedule. nanoserve is my answer in MLX, measured on an M4 with Qwen2.5-0.5B.

ThreadGraph

2026 · Go

Finds goroutine leaks and deadlocks from execution traces. It caught 64 of 68 real bugs.

Go concurrency bugs depend on scheduling, so tests pass and reviewers miss them. ThreadGraph reads a runtime trace, rebuilds which goroutine spawned and blocked which, and runs leak, lock-cycle, and channel analyses. It needs no instrumentation.

scout-deterministic

2026 · Python

Reward-hacking scanners for agent transcripts that finish in 0.4 seconds. The LLM judge takes 560.

Coding agents can pass pytest without solving the task. I wrote four rule-based scanners for Inspect Scout and benchmarked them against its LLM judge on 26 live episodes. They are much faster and cost nothing, with lower precision, and I published the case none of them caught: an agent that made assert 1 + 1 == 3 pass.
